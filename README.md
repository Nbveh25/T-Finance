# T-Finance 💰

**T-Finance** — современное Android приложение для управления личными финансами, разработанное с использованием Clean Architecture и новейших технологий Android разработки.

## 📱 Функционал приложения

### 🔐 Аутентификация
- Регистрация и вход по номеру телефона
- SMS-подтверждение
- Ввод персональных данных (имя пользователя)

### 💵 Управление бюджетом
- Установка месячного дохода
- Распределение бюджета по категориям
- Процентное планирование расходов
- Отслеживание остатка средств

### 📊 Транзакции
- Добавление доходов и расходов
- Категоризация транзакций
- Выбор даты операции
- История всех операций

### 🎯 Цели накопления
- Создание финансовых целей
- Установка суммы и срока достижения
- Отслеживание прогресса накоплений
- Редактирование существующих целей

### 📈 Аналитика расходов
- Просмотр расходов за различные периоды (день, неделя, месяц, год)
- Группировка по категориям
- Визуализация трат

### 🔔 Уведомления
- Push-уведомления о важных событиях
- Напоминания о целях
- Отчеты о тратах

## 🛠 Стек технологий

### Основные технологии
- **Kotlin** — основной язык разработки
- **Android SDK** (API 24+, target API 35)
- **Jetpack Compose** — современный UI toolkit
- **Material Design 3** — система дизайна

### Архитектура
- **Clean Architecture** — разделение на слои Domain, Data, Presentation
- **MVVM** — архитектурный паттерн для UI слоя
- **Repository Pattern** — абстракция для работы с данными

### Dependency Injection
- **Dagger Hilt** — внедрение зависимостей

### Сеть
- **Retrofit** — HTTP клиент
- **Gson** — сериализация JSON
- **OkHttp** — сетевые interceptors

### Навигация
- **Jetpack Navigation Compose** — навигация между экранами
- **Hilt Navigation Compose** — интеграция с DI

### Безопасность
- **Encrypted SharedPreferences** — безопасное хранение данных
- **Google Tink** — криптографическая библиотека
- **Network Security Config** — настройка безопасности сети

### Firebase
- **Firebase Cloud Messaging** — push-уведомления
- **Firebase Analytics** — аналитика использования
- **Firebase Crashlytics** — отслеживание ошибок

### Дополнительные библиотеки
- **Coil** — загрузка изображений
- **ThreeTenABP** — работа с датами
- **Accompanist Flow Layout** — дополнительные UI компоненты

### Инструменты разработки
- **Gradle** с Kotlin DSL
- **KSP** — Kotlin Symbol Processing
- **Android Gradle Plugin** 8.9.1

## 🏗 Архитектура проекта

```
app/
├── data/           # Слой данных
│   ├── remote/     # API и сетевые операции

│   ├── model/      # Модели данных
│   ├── repository/ # Интерфейсы репозиториев
│   ├── usecases/   # Use Cases
│   └── validator/  # Валидация данных

│   ├── screens/    # Экраны приложения

│   ├── navigation/ # Навигация
│   └── theme/      # Тема приложения
```
